An alternate Canvas client.


What is Sail?

Sail is an alternate Canvas client that provides a more modern look and feel than the default Canvas interface!


When will it be available?

I'm currently working on it and hope to have a usable version out soon! If you really want to use it, you can check the GitHub repo and spin up an instance for yourself.


Will Sail be free?

Yes! Sail will be free and open source. You can find the source code on GitHub.
